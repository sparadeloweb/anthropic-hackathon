# Commercial proposal dashboard

This skill generates a self-contained HTML file (tabbed dashboard) that consolidates all sales pipeline outputs for a lead into a professional presentation ready to share with the client.

## When to use

- "Build the proposal web for this lead"
- "Generate the dashboard to send to the client"
- "Put together everything we have for this lead into a page"
- "I need the web presentation for Fernando Bliman"

## What the dashboard includes

The dashboard has 5 tabs:

1. **Business** — Lead data from Google Places API: name, business type, rating, reviews, address, hours, photos.
2. **Design** — Gallery with screenshots of screens designed in Stitch, design system name, color palette.
3. **Proposal** — The commercial proposal text generated by `sales-proposal`.
4. **Budget** — Investment table by role, total, phases, conditions (from `sales-pricing`).
5. **Roadmap** — Executive summary, project phases, assigned team, duration (from `sales-roadmap`).

## Prerequisites

Before running this skill, the lead must have:

- [x] Lead data in `leads/` (output of `/sales-finding-leads`)
- [x] Design in `stitch_designs/<lead>/` (output of `/design-generating-websites`)
- [x] Roadmap in `roadmaps/<lead>/` (output of `/sales-roadmap`)
- [x] Budget in `budgets/<lead>/` (output of `/sales-pricing`)
- [x] Proposal in `proposals/<lead>/proposal.txt` (output of `/sales-proposal`)

If any is missing, tell the user which skill to run first.

## Workflow

1. **List available leads** — find leads that have all 5 required folders/files. Show the list with completeness indicators (check/cross for each prerequisite).

2. **User picks a lead** — or specifies one directly.

3. **Run the script**:
   ```bash
   cd .claude/skills/sales-proposal-web
   python scripts/build_dashboard.py <lead-slug>
   ```
   The script automatically finds all lead files in the repo root folders.

   Generates: `proposals/<lead-slug>/dashboard.html`

4. **Show the path** to the user and let them know they can open the HTML in a browser. Stitch images are embedded as base64 inside the HTML so it's fully self-contained and shareable.

## Output

```
proposals/<lead-slug>/
├── proposal.txt           ← already existed (from /sales-proposal)
└── dashboard.html         ← generated by this skill
```

## Dependencies

- Python 3.10+
